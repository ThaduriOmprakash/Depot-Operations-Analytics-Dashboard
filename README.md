Depot Operations Analytics Dashboard
Depot Operations Analytics Dashboard helps transport depots digitize daily operations through structured data entry, KPI calculations, driver health grading, schedule status monitoring, and performance analytics. Features include MySQL data persistence, dynamic recalculation logic, and historical reporting for operational insights.

Key Features

Tracking : Daily schedules and Services count, required vs available drivers 
Drivers  allocation :  shortages, absentee details and out of Desgination  
SL / MU Reasons : Categorized absence tracking with totals & percentages
History : Select depot + date → retrieve + analyse previous records
Automated Calculations : Percentages, total differences & derived fields auto-update
Database Integration : Persistent storage using MySQL
Admin Login System : Secure login → Add New User → Role-based access


Tech Stack

Frontend  : Streamlit + AgGrid
Backend  :  Python
Database : MySQL
